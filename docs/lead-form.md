# Форма заявок → Telegram

## Що це

Кнопки «Отримати пропозицію» (у hero і в блоці «Чому нам довіряють») відкривають
форму: **імʼя, назва закладу, адреса закладу, телефон, email (необовʼязково)**.

Форма шле дані на серверний обробник, той пересилає їх у Telegram.

## Чому не можна слати в Telegram напряму з сайту

Для запиту до Telegram потрібен токен бота. Усе, що потрапляє в код сайту, видно
кожному відвідувачу (правий клік → «Переглянути код»). Якщо зашити токен туди,
бота одразу вкрадуть: зможуть читати ваші повідомлення і слати від вашого імені.
Тому токен живе тільки на сервері-посереднику.

## Стан

Обробник: `server/lead-worker.js` (Cloudflare Worker).
Адреса обробника задається змінною `VITE_LEAD_ENDPOINT` під час збірки.

**Якщо `VITE_LEAD_ENDPOINT` порожній — форма показує «Форма ще не підключена до
сервера. Напишіть менеджеру напряму».** Тобто заявки нікуди не йдуть. Перевірити
можна так: зібрати проєкт і пошукати URL у бандлі.

```bash
npm run build && grep -o "https://[a-z0-9.-]*workers.dev" dist/assets/*.js
```

## Як підняти обробник (одноразово, ~10 хвилин)

1. **Бот.** У Telegram знайти `@BotFather` → `/newbot` → отримати токен.
   Можна взяти й наявного бота УкрХаляль — тоді новий не потрібен.

2. **Куди слати.** Написати своєму боту будь-що, потім відкрити в браузері
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` і взяти `chat.id` з відповіді.
   Для групи — додати бота в групу і зробити те саме.

3. **Worker.** На dash.cloudflare.com → Workers & Pages → Create → Worker.
   Вставити вміст `server/lead-worker.js`, задеплоїти.

4. **Змінні.** У налаштуваннях Worker'а → Settings → Variables:
   - `TELEGRAM_BOT_TOKEN` — токен з кроку 1, обовʼязково через **Encrypt** (секрет)
   - `TELEGRAM_CHAT_ID` — id з кроку 2
   - `ALLOWED_ORIGIN` — `https://horeca-ukrhalal.com.ua`

   `ALLOWED_ORIGIN` потрібен, щоб ендпоінт не спамили з чужих сайтів: Worker
   прийме заявку лише якщо запит прийшов з нашого домену.

5. **Підключити до сайту.** Створити в корені проєкту файл `.env`:

   ```
   VITE_LEAD_ENDPOINT=https://<імʼя-воркера>.<акаунт>.workers.dev
   ```

   `.env` у `.gitignore` — у репозиторій він не потрапляє. Далі звичайний деплой
   (`docs/deployment.md`): змінна вшивається у бандл під час `npm run build`.

## Перевірка після підключення

Відкрити сайт, заповнити форму, надіслати. Має зʼявитись «Заявку прийнято», а в
Telegram — повідомлення. Якщо замість цього помилка — дивитись логи Worker'а
(вкладка Logs у Cloudflare), там буде видно, що саме відповів Telegram.
