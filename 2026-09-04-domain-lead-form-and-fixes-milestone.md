## 2. Власний домен horeca-ukrhalal.com.ua

Куплено на X-Host (~399 грн/рік). DNS: 4×A на apex → GitHub Pages IPs (185.199.108/109/110/111.153), `www` → CNAME → `daud-coder.github.io.`. `mail`/`MX`/`SPF`/`NS` записи X-Host не чіпали — пошти на цьому домені нема.

Код: `public/CNAME` = `horeca-ukrhalal.com.ua`. **Критично:** `vite.config.ts` `base` змінено з `/ukrhalal-horeca/` на `/` — власний домен на GitHub Pages завжди обслуговується з кореня репозиторію, не з підпапки. Без цього — біла сторінка (всі asset-шляхи вказують у нікуди). Перевіряти зміни `base` треба через `vite preview` на зібраний `dist/`, НЕ через `vite dev` — dev-сервер завжди на `/` незалежно від конфіга білда, бага не зловить.

**HTTPS-сертифікат GitHub видав не одразу** — після налаштування DNS минуло понад 13 годин без прогресу (при типових ~1-2 год). Помічений робочий трюк: `PUT /repos/{owner}/{repo}/pages` через `gh api` спершу з порожнім `cname`, потім знову зі справжнім — це видимо перезапускає видачу сертифіката (`https_certificate.state` пройшов new→approved за ~20 сек після другого виклику). `status` сторінки на секунду стає `"errored"` одразу після цього — це шум білд-пайплайна від зміни домену, не реальний збій, сам минає за ~15 сек. Окремо треба `PUT .../pages -F https_enforced=true` (саме `-F`, не `-f` — `gh api -f` шле рядок, а GitHub чекає JSON boolean, інакше 422) щоб `http://` реально редіректив на `https://`.

## 3. Форма заявок реально працює — Cloudflare Worker → Telegram

Обидві кнопки «Отримати пропозицію» (hero + блок «Чому нам довіряють») відкривають модалку, яка тепер справді шле заявку власнику в Telegram, а не показує "форма ще не підключена".

**Стек:**
- `server/lead-worker.js` — Cloudflare Worker, приймає POST, шле в Telegram Bot API. Токен бота/chat_id/дозволений origin — лише в секретах Cloudflare (`wrangler secret put`), НІКОЛИ не в коді чи в git.
- `server/wrangler.toml` — конфіг (`name = "ukrhalal-lead-worker"`).
- Публічний URL воркера: `https://ukrhalal-lead-worker.ukrhalal-daud.workers.dev`
- Сайтовий `.env` (в `.gitignore`, не в git) — `VITE_LEAD_ENDPOINT=` той URL, вшивається в бандл при `npm run build`.
- Бот: `@ukrhalal_zayavky_bot`. Chat_id власника: `399323653`.

**Форма тепер має поле «Адреса закладу»** (обовʼязкове, поруч із імʼям/закладом/телефоном/email) — власник попросив, бо адреса потрібна для розрахунку доставки.

**Гочки Cloudflare-акаунту (був абсолютно новий):**
1. `wrangler deploy` без зареєстрованого `workers.dev`-піддомену намагається автоматично взяти піддомен **з імені поточної директорії** (тут — "server", бо там лежить `wrangler.toml`) — якщо слово зайняте кимось іншим, падає з незрозумілою помилкою. Фікс: `PUT /accounts/{id}/workers/subdomain` з `{"subdomain": "ukrhalal-daud"}` — одноразова настройка на весь акаунт.
2. Щойно зареєстрований `*.workers.dev` не одразу має живий TLS — перший запит дав справжній "SSL/TLS alert handshake failure" і з curl, і з Node fetch (тобто не баг локального клієнта) — минуло само за ~20 сек.
3. Шаблон токена "Edit Cloudflare Workers" в дашборді має зайвий рядок `Zone: Workers Routes: Edit`, який вимагає вибору зони — а домен не заведений у Cloudflare DNS (лишається на X-Host+GitHub Pages), тому зону нізвідки взяти, і "Continue to summary" блокується помилкою "Choose a zone resource". Фікс: видалити цей рядок правил (кнопка X) перед продовженням — Account-scoped права (Workers Scripts/KV/R2/Pages тощо) — все, що реально треба.

**Токен бота власник присилав у чат** — використано одноразово для налаштування й НЕ збережено в жодному файлі. Власнику сказано зробити `/revoke` у `@BotFather` і переіздати — **перевір, чи він це зробив**, якщо ні — нагадати.

## 4. Дрібніші фікси цієї сесії

- **Hero → миттєвий перехід до категорії.** Клік по категорії в hero (Яловичина/Баранина/…) прокручував ~4700px плавною анімацією через увесь сайт замість одразу відкривати розділ. `behavior: 'auto'` не спрацював би — в `index.css` глобально `scroll-behavior: smooth`, і `'auto'` саме віддає рішення цьому CSS. Потрібен явний `'instant'` (`Hero.tsx`).
- **`#advantages`-якір ховався під шапкою** — не мав `scroll-mt-[92px]` на відміну від інших секцій. Додано.
- **Мертва кнопка «УМОВИ СПІВПРАЦІ»** (вела на неіснуючий `#terms`) — прибрана за рішенням власника.
- **Порожнеча в лівій колонці «Чому нам довіряють»** (лишилась після видалення тієї кнопки) — заповнена робочою кнопкою «Отримати пропозицію» (та ж модалка) + фото `advantages-meat-prep-v3.webp` (мʼясник з ножем, фото власника). Тільки десктоп (`lg:block`) — на мобільному колонки складаються, порожнечі нема.
- **Дубль мʼясного фото на десктопі** — декоративна стрічка зі стейками (`advantages-steaks-board.webp`) між «Чому нам довіряють» і «Про компанію» стала читатись як зайвий другий сирий-мʼясний кадр поруч із новим фото з п.4 вище (ліва колонка коротша за грід із 6 карток — обидва фото в одному екрані прокрутки). Прибрано лише на `lg+` (`lg:hidden`), на мобільному лишилась — там це єдиний мʼясний візуал у переході.
- **Модалка форми заявки не мала обмеження висоти** — з появою поля «Адреса» вміст почав перевищувати висоту вʼюпорта на звичайних ноутбучних екранах, форма обрізалась зверху й знизу, кнопку "Надіслати" не було видно. Фікс: `max-h-[calc(100dvh-3rem)]` + внутрішній `overflow-y-auto` на самому вмісті (заголовок з хрестиком закриття залишається на місці). Заразом ущільнено відступи форми (fieldset gap 16→12px, label→input 8→6px, padding інпутів 12→10px).
- **Favicon обрізало у вкладці браузера** — сам вихідний PNG мав роги бика впритул до країв 512×512 полотна. Перекроплено з "сяючого" золотого логотипу шапки (той самий стиль), додано рівномірний відступ з усіх боків. Перевірено на 32px/16px.
- **SEO-мінімум доданий**: `robots.txt`, `sitemap.xml` (один URL — сайт одна сторінка з якорями), Open Graph + Twitter Card теги (превʼю 1200×630 з кухонного фото, `public/images/og-cover.jpg`), JSON-LD `Organization` (назва/лого/опис/телефони/areaServed: Київ — адресу НЕ вигадано, її нема в `contacts.ts`), `<link rel="canonical">`.

## 5. Технічні пастки, вже спіймані цієї сесії (щоб не наступати вдруге)

- **Browser pane (`mcp__Claude_Browser__*`) інколи видає ЛОЖНІ "критичні баги"** — панель лишається `visibilityState:"hidden"` попри `tabs_select`, `requestAnimationFrame` взагалі не спрацьовує (перевіряти явно), і тоді `scroll-behavior:smooth`/`whileInView`-reveal виглядають "мертвими", хоча насправді працюють. Рецепт: відтворювати знахідки з Browser pane в **headless Playwright** (`npm i playwright@latest` у scratchpad, `~/Library/Caches/ms-playwright` вже має завантажені браузери) ПЕРЕД тим, як щось правити — інакше є ризик виломати робочий код.
- **Chrome кешує favicon окремо від сторінки**, звичайний Cmd+Shift+R не завжди його оновлює — треба закрити всі вкладки сайту й повністю перезапустити Chrome.
- **Паралельні AI-інструменти на цьому ж репозиторії небезпечні.** Цієї сесії інструмент "Antigravity" (не Codex, окремий застосунок), запущений власником на іншому завданні (правка прайсу), непомітно торкнувся `public/logo/*.png` + `Header.tsx`/`MobileMenu.tsx` (висота лого) в цьому ж репо, незакомічено, паралельно з моєю власною роботою. Я мало не закомітив цей чужий diff разом зі своїм — зловив тільки через `git status` одразу після коміту. Завжди перевіряти `git status` відразу після будь-якого коміту в цьому репо, не тільки перед.
- **`gh api -f` шле рядок, не boolean** — для полів типу `https_enforced` треба `-F`, інакше 422 "is not of type boolean".
