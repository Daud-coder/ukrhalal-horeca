## Бизнес-контекст (для будущих решений по фиче-скоупу)

Сайт — посадочная страница для лидогенерации, план развёртывания:
1. Завести Instagram и TikTok (ещё не существуют).
2. Генерировать видео через ИИ, постить в эти соцсети.
3. Лиды из соцсетей → переход на этот сайт.
4. На сайте — мессенджер-виджеты (Telegram/WhatsApp/Viber), которые подхватывает ИИ-агент: квалифицирует клиента, закрывает сам либо передаёт живому менеджеру.

Из этого следует: контакты и мессенджер-кнопки в футере — не декоративные, это точка входа в будущую воронку. Делать их с реальными ссылками, а не заглушками, как только появятся данные.

## Рабочие правила

- Эта папка («Версія 9») — единственная рабочая версия сайта. Продолжаем дорабатывать именно от текущего утверждённого состояния, старые черновики в других папках не используются как основа.
- Визуальный эталон — только утверждённые скриншоты/дизайн-QA (`design-qa.md`), не менять утверждённую композицию без новой QA-сверки.
- Делегирование в Codex/`codex-worker` сейчас не применяется — не потому что модель отключена как метод, а потому что Codex CLI на данный момент не работает/недоступен. Пока это так, код пишет напрямую Claude Code, без связки прораб/трудяга. Если Codex снова заработает, к вопросу делегирования можно будет вернуться.
- Копия на сайте — українською; эта инструкция и рабочая переписка — русский.
